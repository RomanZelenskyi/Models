# Проверка внешнего расчётного ядра

12 октября 2026 года. Все запуски выполнены на отдельных копиях; исходный каталог Delphi не изменялся.

| EXE / вход | Код завершения | Результат |
|---|---|---|
| Dross.exe / сформированный data.dat из dross-sau.inm | -1073741795 / 0xC000001D | param.dat и rez.dat не созданы |
| Dross.exe / исходные записи Delphi без исторического хвоста результатов | -1073741795 / 0xC000001D | param.dat и rez.dat не созданы |
| Dross.exe / повтор вне песочницы | -1073741795 / 0xC000001D | выходные результаты не созданы |
| dinam.exe / dinam-sau.inm | -1073741795 / 0xC000001D | param.dat не создан |
| kldm.exe / kldm.inm | -1073741760 / 0xC0000040 | param.dat не создан |

Причина аварий не установлена. Совпадение ошибки Dross на исходном вводе и вне песочницы не позволяет считать проблему исключительно ошибкой нового сериализатора.

Автоматические проверки подтверждают подготовку отдельного рабочего каталога, передачу данных, чтение результатов, завершение и отмену на тестовом процессе. Они не подтверждают численное соответствие математического ядра.

Для завершения проверки требуется совместимый работающий расчётный EXE либо исходники ядра. Затем нужно сравнить результаты Delphi и WPF на одинаковых INM/DAT с заданным численным допуском.
